텍스트 타브

텍스트 불러오기

이 에디터에서 내보낸 텍스트 타브를 붙여 넣으세요. 현재 악보는 모두 바뀌지만 실행 취소할 수 있어요.

이미지로 저장

이미지를 길게 누르거나(폰) 마우스 오른쪽 버튼(PC)으로 저장하세요.

코드 넣기

선택한 칸에 6줄 운지를 한 번에 넣고, 코드 이름을 메모로 달아요. 뮤트(x) 줄은 비워 둡니다.

사용법

  • 악보의 칸을 탭하면 세로 한 칸(16분음표)이 선택돼요. 숫자판으로 프렛을 넣고, 1이나 2를 누르면 두 자리(10~24)를 잠시 기다려요.
  • 프렛보드로 바꾸면 지판을 직접 눌러 입력해요. 여러 줄을 눌러 코드를 만들기 좋고, 같은 자리를 다시 누르면 지워져요.
  • h p b / \ ~ 는 직전에 넣은 음에 붙어요. 재생하면 b는 반음 벤딩, ~는 비브라토, / \ 는 다음 음으로 미끄러져요.
  • ▶는 선택한 마디부터 재생해요. 반복을 "이 마디"로 두면 한 마디만 계속 돌아 연습하기 좋아요.
  • 마디 번호를 탭하면 그 마디 첫 칸으로 이동해요. 마디 위 빈 줄(+)을 탭하면 코드 이름, 가사, 구간 이름을 적어요.
  • 아래 ▼를 누르면 입력판을 접어 악보를 넓게 볼 수 있어요. 칸을 탭하면 다시 펼쳐져요.
  • 소리는 설정에서 악기(어쿠스틱·나일론·일렉 클린·드라이브), 음량, 리버브를 바꿀 수 있어요. 여러 줄을 같이 치면 스트럼처럼 살짝 시간차가 나요.
  • 입력 내용은 이 기기 브라우저에만 저장돼요. 다른 기기로 옮기려면 내보내기 → 텍스트를 복사해 불러오세요.

키보드

  • 0~9 프렛, h p b / \ ~ x 기법, Backspace 지우기
  • 방향키 이동, Shift+좌우 또는 Tab 한 박 이동, Home End 마디 처음/끝
  • Space 재생/정지, Enter 메모, Esc 선택 해제
  • Ctrl+Z 실행 취소, Ctrl+C / V 마디 복사·붙여넣기
